# GROMACS smoke fixture

These coordinates and topology describe a synthetic one-atom argon system.
They were authored specifically for MolDynStudio's tests and contain no
coordinates, parameters, or other data copied from an external scientific
dataset.

related rights in `argon.gro` and `topol.top` under
[CC0 1.0 Universal](https://creativecommons.org/publicdomain/zero/1.0/), so
the tiny fixture can be redistributed with MolDynStudio and its test suite.
